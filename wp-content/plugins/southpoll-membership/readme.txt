Membership, farm directory, and cattle classifieds for the South Poll Grass Cattle Association.

== Description ==

Custom plugin replacing the Classified Listing plugin family on southpoll.com. Provides member accounts, farm pages and a
member directory, cattle classifieds, Stripe membership payments, favorites, saved searches, notifications, and admin tools.

Design and build documentation lives outside the plugin in the project's temp/ knowledge base.
